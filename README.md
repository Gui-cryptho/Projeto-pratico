# Projeto Prático

Este projeto é uma aplicação web desenvolvida com Next.js, React e TypeScript.

## Stack utilizada

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- ESLint
- Prettier
- Husky
- Commitlint

## Requisitos

Antes de começar, certifique-se de ter instalado:

- Node.js 20 ou superior
- pnpm 9 ou superior

## Instalação

1. Clone o repositório:

   ```bash
   git clone <url-do-repositorio>
   cd projeto-pratico
   ```

2. Instale as dependências:
   ```bash
   pnpm install
   ```

## Como rodar o projeto

### Desenvolvimento

```bash
pnpm dev
```

A aplicação ficará disponível em:

```text
http://localhost:3000
```

### Build de produção

```bash
pnpm build
```

### Executar build de produção

```bash
pnpm start
```

## Scripts disponíveis

- `pnpm dev` — inicia o servidor de desenvolvimento
- `pnpm build` — gera a build de produção
- `pnpm start` — roda a aplicação em modo produção
- `pnpm lint` — executa a análise estática com ESLint

## Estrutura do projeto

- `src/app` — páginas e layout da aplicação
- `src/modules` — módulos da aplicação
- `src/shared` — componentes, hooks, utilidades e tipos reutilizáveis
- `public` — arquivos estáticos
